# Turnery：颜色并进显示卡片，样式一排四个

- 状态：已实现（2026-11-17，Jim「OK 直接在这开动」；落地记录在文末）
- 日期：2026-11-17
- 范围：3D 视图左侧工具列的「显示样式」卡片和「颜色」按钮；W、A 两个快捷键；半透明下的颜色。桌面版和网页工作台共用这一块。
- 不在范围：agent 那边 `look` 的 `plain`、`export` 的 `style` 参数（MCP 工具不变）；设颜色的入口（左栏圆点、时间线左端、拆件零件的小标签）；`components/ui/segmented.tsx`（和 jim-uiux 上游保持一致）；工具列别的按钮。
- 相关：`2026-11-11-turnery-workbench-layout.md`（工具列分组、单字母快捷键，`A 颜色` 在那里定的）

## 为什么

Jim 用 0.10.0 时：外壳没设颜色，装配视图一片白，以为颜色坏了；找了一圈才知道颜色是工具列上单独一个调色板按钮。「显示样式」卡片（着色 / 线描 / 半透明、透视 / 正交）是后来加的，颜色没挪进去，「看起来怎么样」分成了两个按钮。

读代码：

- 颜色开关（`ft-studio-looks`）和样式（`ft-studio-view` 的 `style`）各存各的；线描下颜色按钮置灰。
- 半透明现在跟着颜色开关：开着是按零件颜色的半透明，关着是中性灰的半透明。
- `Segmented` 不支持单个选项置灰。

## 设计

- 「显示样式」卡片的「样式」一排改成四个：**白模 / 彩色 / 线描 / 半透明**（W）；「投影」一排不变（O）。「着色」这个词拿掉：白模和彩色都是着色。
- 工具列去掉单独的「颜色」按钮。
- 半透明一律按零件的颜色画（装配里切半透明就是为了分清零件）；没设颜色的零件照旧是中性灰。去掉的组合只有「半透明 + 白模」。
- 线描也不看颜色开关：透明零件在线描里始终透明（原来从白模切过去会画成不透明的纸色，从彩色切过去又是透明的）。只有着色（白模 / 彩色）看开关。
- W：白模 → 彩色 → 线描 → 半透明 → 白模。A：白模 ⇄ 彩色；在线描、半透明时按 A 回到彩色；模型一个颜色都没有时 A 不动（和原来一样）。
- 选了「彩色」但模型一个零件都没设颜色：卡片底下写「零件还没设颜色，所以看起来是白模：点零件名旁边的圆点设颜色。」
- 显示按钮的提示写出现在的样式和投影；不是常用的时候亮起：线描、半透明、正交，或者有颜色却选了白模（免得以为颜色坏了）。
- 存储不变：还是 `ft-studio-view` 的 `style`（shaded / lines / xray）加 `ft-studio-looks`（on / off），四选一只是界面上合起来显示。老用户升级后看到的一样，只有原来「半透明 + 白模」的会变成按颜色的半透明。

## 验收

1. 显示卡片「样式」一排四个：白模 / 彩色 / 线描 / 半透明；「投影」一排不变。
2. 左侧工具列没有单独的「颜色」按钮。
3. W 依次 白模 → 彩色 → 线描 → 半透明 → 白模；O 不变。
4. A 在白模和彩色之间切；线描、半透明下按 A 到彩色；模型没有颜色时 A 不动。
5. 半透明按零件的颜色画，和颜色开关无关；没设颜色的零件是中性灰。线描里透明零件始终透明，和怎么切到线描无关。
6. 选「彩色」而模型没有颜色时，卡片里有那句提示；有颜色时没有。
7. 显示按钮的提示写出样式和投影；线描、半透明、正交、有颜色却选白模时亮起。
8. 原来存下的选择照常读出，不用迁移。
9. 快捷键表 W、A 两行是新的说法。
10. 「导出视图」的图片按现在的四种样式出（半透明带颜色）。

## 落地记录（2026-11-17）

做了什么：上面清单全部；`app/src/studio/view-look.ts` 是换算，界面和快捷键都走它。

和计划不一样的：

- 「彩色」没有置灰：`Segmented` 不支持单个选项禁用，`components/ui/` 又要和 jim-uiux 上游一致，不能改。改成照常能选，没颜色时卡片底下写明为什么看起来是白模；提示也写进了显示按钮的悬停说明。
- 提示文字写成「用零件名旁边或时间线左端的圆点设颜色」：单个零件的颜色圆点在时间线左端，装配和拆件的在零件名旁边；只读的分享页只说「零件还没设颜色」。
- 线描也不看颜色开关（独立审查发现）：开关并进卡片以后看不见了，线描却还跟着它，透明零件会因为走的路不同时透时不透。

自己定的：

- 半透明一律带颜色 → 去掉「半透明 + 白模」（装配里切半透明就是为了分清零件，Jim 的方案里也是这样）。
- A 在线描、半透明下按 → 回到彩色（A 是「颜色」键，回到最常用的样子）；模型没有颜色时 A 不动（和原来一样）。
- 有颜色却选白模时显示按钮亮起（Jim 这次就是被一片白搞糊涂的）。

验证：`npm run check`（484 个单测）、`npm run build`、desktop 的 check / test / build 通过；e2e `studio.e2e.ts` 12 个都过（新加 1 个）；浏览器里在 `/studio?start=flange` 手测：设橙色后彩色、白模、半透明，从白模切半透明仍带颜色，W、A 轮换，设成透明质感后从白模切线描仍透明。没在 Electron 桌面窗口里看过（同一个组件）。
